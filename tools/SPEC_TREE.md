# ТЗ: новое дерево фокусов

Это точный контракт формата. Соблюдай его буквально — движок читает JSON
по этим полям, а проверка падает при любом отклонении.

## Что делать

Создай ТРИ файла для одной цивилизации:

1. `data/focus/<ТЕГ>/<ТЕГ>_focus.json` — дерево фокусов
2. `data/lang/focus_<ТЕГ>_ru.properties` — переводы (RU + `_EN`)
3. `tools/make_<ТЕГ>_icons.py` — генератор иконок

## 1. Формат дерева

```json
{
 "name": "<Название страны по-русски>",
 "CivTag": "<ТЕГ>",
 "FOCUS_LIST": [
  {
   "name": "BE2_F_<ПРЕФИКС>_<КЛЮЧ>",
   "present": ["BE2_F_<ПРЕФИКС>_<КЛЮЧ>", "..."],
   "condition": [],
   "describe": "BE2_FD_<ПРЕФИКС>_<КЛЮЧ>",
   "icon": "focus_<трёхбуквенный префикс>_<ключ>",
   "effect": [ {эффект}, ... ],
   "FinishTurns": 40,
   "AI_Trend": 50
  }
 ]
}
```

- `<ПРЕФИКС>` — короткий код цивилизации заглавными: `GERN`, `RUSI`, `ENG`, `POL`.
- Триггер иконки: `focus_ger_<ключ>.png` для `GERN`/`ENG` (тег `ger_n`/`eng`),
  `focus_rus_<ключ>.png` для `RUSI` (тег `rus_i`), `focus_pol_<ключ>.png` для `POL`.
  То есть префикс иконки — это первые три буквы ТЕГА, а не ПРЕФИКСА ключа.
- `present` — список фокусов, которые должны быть выполнены. Пустой `[]` = корень.
- `condition` — либо `[]`, либо годовые ограничения:
  `{"type": "Time_Reach", "Year": 1940, "Month": 0, "Day": 0}`
- `FinishTurns` — 25…90, чем масштабнее фокус, тем дольше.
- `AI_Trend` — 20…60, насколько ИИ заинтересован (влияет только на ИИ).

### Жёсткие правила дерева

- Ровно 35 фокусов.
- 4–5 фокусов без `present` (корни), остальные — продолжения.
- Все 35 фокусов **достижимы** от корней (проверь обходом в ширину).
- Никаких битых ссылок: каждый ключ в `present` и в `condition` должен существовать.
- Имена `name` и `describe` уникальны.
- Никаких эффектов типа `Event` — их в новых деревьях нет принципиально.
- Годовые условия — только на поздних/войсковых фокусах, их должно быть 8–14 штук.

## 2. Эффекты

Только эти типы. Ничего другого движок не поймёт.

```json
{"type": "Stat", "Name": "<ПОКАЗАТЕЛЬ>", "Value": <число>}
{"type": "Modifier", "Name": "<МОДИФИКАТОР>", "Value": <дробное>, "Turns": <0 или 60-80>}
{"type": "Money", "Value": <целое, может быть отрицательным>}
{"type": "Tech", "Value": <1..3>}
{"type": "Happiness", "Value": <целое от -25 до +25>}
{"type": "Government", "To": "<ПРАВИТЕЛЬСТВО>"}
{"type": "CivilWar"}
{"type": "Relation", "CivTag": "*", "Relation": <дробное -1..1>}
{"type": "Alliance", "CivTag": "<ТЕГ>", "Name": "<имя нового союза (необязательно)>"}
{"type": "NonAggression", "CivTag": "<ТЕГ>", "Turns": <1..365>}
{"type": "War", "CivTag": "<ТЕГ>"}
```

`Turns: 0` — постоянный модификатор (для Modifier). `Turns: 60` — на 60 ходов.

### Дипломатические эффекты (союзы и войны)

Эти типы добавлены в движок (Focus_Accomplish_Alliance/NonAggression/War) и
работают на реальных тегах цивилизаций:

- `Alliance` — заключить союз с `<ТЕГ>`. Если союзов ещё нет ни у кого из
  сторон — создаётся новый (имя из `Name` или случайное), иначе вступаем во
  союз второй стороны. Отношения сторон поднимаются не ниже 60 (война между
  союзниками движком запрещена). Добавь второй `Alliance` рядом — например
  `Alliance: ita` и `Alliance: jap` — и обе страны окажутся в одном союзе.
- `NonAggression` — пакт о ненападении с `<ТЕГ>` на `Turns` ходов, отношения
  поднимаются до ~35. Пакт не мешает объявить войну третьим странам.
- `War` — немедленно объявить войну `<ТЕГ>` (движок сам опускает отношения
  ниже порога, чтобы `declareWar` сработал, и форсирует объявление).

Теги пишутся **настоящими** тегами стран, а не идеологией: в сценарии «Европа»
Италия — это `ita_f`, Болгария — `bul_n`, а Турция — `tur_i`. Эффекты сравнивают
тег и часть до подчёркивания, поэтому `ita`/`bul`/`tur` находят нужную страну.

Проверенные теги для сценария «Европа»: Германия `ger_f`, СССР `rus_c`,
Великобритания `uni`, Франция `fra`, Польша `pol`, Австрия `atr`,
Чехословакия `czsl` (тег `cze` — пустая страна, аннексия от неё не сработает),
Данциг `fcd`, Финляндия `fin`, Прибалтика `est` / `lat` / `lit`,
Румыния `rom`, Болгария `bul`, Венгрия `hun`, Югославия `yugo`,
Дания `den`, Норвегия `nor`, Швеция `swe`, Турция `tur`, Греция `gre`,
Иран `ira`, Испания `spa`. Японии в европейском сценарии нет: такой эффект
пропускается без падения, это видно в логе.

### Аннексия (`Annexation`)

Единственный эффект, который меняет карту: провинции переходят к стране
вместе с городами, границы и мирная карта меняются по-настоящему.
`CivTag` указывает страну-жертву, `*` — самую слабую из соседей,
`Provinces` — сколько провинций забрать, `Share` — минимальную долю своей
национальности в провинции (`0` — берётся любая, в первую очередь приграничная),
`War: true` — сначала объявить войну.

Делай из фокуса аннексию, а не `Stat Population`, когда название фокуса
обещает территорию: «Аншлюс» от `atr`, «Судеты» от `czsl`, «Данциг» от `fcd`,
«Мемель» от `lit`, «Польская кампания» — война с `pol` плюс его провинции.

### Показатели `Stat`

| Name | Значение | Типичный масштаб |
|---|---|---|
| `Stability` | 0.05…0.25 | прочность власти |
| `DiplomacyPoints` | 50…400 | очки дипломатии |
| `ManPower` | 20000…500000 | живое мясо |
| `MilitaryPoints` | 200…4000 | очки армии |
| `NuclearWeapons` | 1…2 | бомбы |
| `Food` | ±1000…5000 | еда |

### Правительства для `Government` (писать имя точно)

`ParlamentaricRepulic`, `MixedRepublic`, `PresidentalRepublic`, `AbsoluteMonarchy`,
`ConstuntionalMonarchy`, `ElectiveMonarchy`, `Oligarchy`, `DirectDemocracy`,
`Dictatorshipoftheproletariat`, `Theocracy`, `Autocracy`, `anarhism`,
`technocracy`, `Bonapartism`, `Horde`, `CityState`, `Tribal`, `Rebels`,
`TerroristicOrganisation`

Осторожно: смена правительства меняет тег цивилизации (дописывается буква
`Extra_Tag`). Если фокус меняет правительство, не используй потом в этом
дереве эффекты, зависящие от тега.

## 3. Переводы (`data/lang/focus_<ТЕГ>_ru.properties`)

Ровно 128 строк-ключей: на каждый из 35 фокусов четыре ключа.

```
BE2_F_<ПРЕФИКС>_<КЛЮЧ> = <русское название>
BE2_F_<ПРЕФИКС>_<КЛЮЧ>_EN = <English title>
BE2_FD_<ПРЕФИКС>_<КЛЮЧ> = <описание по-русски, 2-3 предложения>
BE2_FD_<ПРЕФИКС>_<КЛЮЧ>_EN = <English description>
```

- Файл UTF-8, перевод строки обычный (`\n`), строки вида `КЛЮЧ = значение`.
- Первая строка — комментарий `# Переводы ...`, между блоками пустые строки.
- Описание = что происходит в игре и чем это обернётся. Без воды, без «мы».
- Никаких латинских слов внутри русского текста.
- Никаких лишних ключей, никаких ключей со значением `0`.

## 4. Иконки (`tools/make_<ТЕГ>_icons.py`)

Образец — `tools/make_ger_rus_icons.py`. Копируй его структуру целиком.

```python
#!/usr/bin/env python3
"""Рисует иконки фокусов <СТРАНА> - 35 штук.

  usage: make_<ТЕГ>_icons.py <каталог gfx/goals>
"""
import os
import sys

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))

from focus_icons import render_all, sym_star, sym_...  # noqa: E402

TABLE = {
    '<ключ>': sym_star,
    ...
}


def main():
    print('    нарисовано иконок: %d' % render_all(sys.argv[1], {'<ТЕГ>': TABLE}))
    return 0


if __name__ == '__main__':
    sys.exit(main())
```

- `TABLE` содержит ровно 35 записей, ключи совпадают с ключами `icon` в JSON.
- Эмблемы бери из `focus_icons.py` (54 штуки: `sym_star`, `sym_tank`,
  `sym_ship`, `sym_jet`, `sym_atom`, `sym_wheat`, `sym_factory`, `sym_rail`,
  `sym_map`, `sym_swords`, `sym_shield`, `sym_gate`, `sym_star_ring` и т. д.).
  **Не выдумывай новых имён** — импортируй только существующие, иначе скрипт упадёт.
- Список доступных эмблем: `python3 -c "import sys;sys.path.insert(0,'.');import focus_icons as F;print([n for n in dir(F) if n.startswith('sym_')])"`.
- Эмблемы по возможности разные; одно и то же на разных фокусах — только если
  темы действительно совпадают.
- Палитра для тегов уже есть в `focus_icons.PALETTES`: `ger_n`, `rus_i`, `eng`, `pol`.

## 6. Отладочный прогон эффектов без кликов (маркер `debug_focus`)

Чтобы проверить эффекты фокуса в живой игре без управления мышью, положи в
папку игры файл `debug_focus` (строки `<тег> <имя фокуса>`; `play_as=<тег>`
сажает игрока за страну, `civs` печатает страны партии):

```
play_as=ger_f
civs
ger_f BE2_F_GER_MOLOTOV
ger_f BE2_F_GER_AXIS
rus_c BE2_F_RUS_FINLAND
```

Сразу после загрузки сценария фокусы будут выполнены как настоящие
(`beginApply` + `accomplish` + описание эффектов как в тултипе). Результат —
в `logs/be2.log`: строки `Focus alliance: ger_f + rus_c (allianceID 1)`,
`Focus non-aggression: ...`, `Focus war: ...`, `Focus annex: ...`.
Маркер удалять не надо — без файла ничего не происходит.

Строка `civs` (с необязательным фильтром, например `civs чех`) печатает
`CIV <id> <тег> <название> <провинций>` по всем странам партии. Это
единственный надёжный способ узнать настоящие теги сценария: они не всегда
совпадают с привычными (`cze` в «Европе» — пустая страна без провинций, а
Чехословакия называется `czsl_n`).

Раскладку дерева (наложения узлов) можно проверить маркером `debug_layout`:
в нём перечислены теги через пробел, и при загрузке игры в лог уходит
`TREE <тег> <узлов>` и `LAYOUT <фокус> <x> <y> <w> <h>` для каждого узла.
